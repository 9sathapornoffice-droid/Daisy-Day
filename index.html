วิธีนำไฟล์ไปใส่ GitHub:
1 กดปุ่ม "ดาวน์โหลดไฟล์ app.js ที่อัปเดตแล้ว" ด้านบน
2 เปิดลิงก์ GitHub Daisy-Day Upload
3 ลากไฟล์ app.js ที่เพิ่งดาวน์โหลดไปวางทับไฟล์เดิม แล้วกด Commit changes เสร็จเรียบร้อย!
